Phase Distorter 0.2.1 - source and dependency notices

The CPU program translation originates from the EarthBound / Mother 2 source
disassembly maintained at https://github.com/Herringway/ebsrc, upstream revision
0197d6c13ef11ad3280e9388e08a646ab1030d15. The C++ implementation, translation
tools, hardware model, importer and frontend come from this independent port.
No blanket license is assigned to upstream or third-party work by this package.

This runnable bundle contains no retail ROM, extracted gameplay asset pack, save, or
map artwork or dialogue. The debug teleport picker contains place names and
landing coordinates; its source references are documented in the full source
snapshot at cpp/docs/debug-tools.md. The supplied Saturn icon is application artwork.
Obtain the matching full Phase Distorter source snapshot from the same project
release for build instructions, generated program sources, and the exact used
dependency sources. Source code is not duplicated in this runnable ZIP.
